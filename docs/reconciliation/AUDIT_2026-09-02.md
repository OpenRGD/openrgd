## Canonical hashing decision

The adopted branch profile is:

```text
OPENRGD_SOURCE_TREE_SHA256_V1
```

It commits the selected modular source tree, not a generated monolithic file.

For each selected source it commits:

```text
relative POSIX path
media type
normalized byte count
SHA-256 of exact source bytes
```

JSONC comments, spelling and formatting are part of the commitment. `.gitattributes` establishes LF normalization for tracked text.

To avoid a recursive hash equation, only this field in `spec/manifest.jsonc` is normalized during calculation:

```text
meta_group.integrity_hash_str = "sha256:SELF"
```

Every other manifest byte remains committed. The path-sorted source index is serialized as UTF-8 canonical JSON using sorted keys, compact separators, no NaN values and unescaped Unicode. SHA-256 of those index bytes produces the declared root.

Scope is intentionally limited to the OpenRGD `spec/` source/profile. It does not claim to sign or authenticate:

- implementation code;
- candidate contracts;
- external component repositories;
- CI artifacts;
- releases;
- authorship or governance approval.

Commit and release signing remain separate open decisions.

## Generated-artifact and example cleanup

### Removed recursive aggregate products

The active tree no longer contains:

```text
spec/01_spec.jsonc ... spec/06_spec.jsonc
spec/openrgd_unified_spec.json
spec/openrgd_unified_spec.jsonc
standard/01_spec.json ... standard/06_spec.json
standard/openrgd_unified_spec.json
standard/benchmarks/
```

Direct inspection showed that per-domain JSONC bundles could ingest older copies of themselves, while the unified JSONC bundle then ingested those already recursive domain bundles. Multiple generator implementations also emitted wall-clock timestamps, preventing deterministic byte identity.

**Classification:** `SUPERSEDED_RECURSIVE_GENERATED_OUTPUT`.

### Removed duplicate robot profiles

Both:

```text
RGD-ur5/
my-robots/RGD-ur5/
```

shared the exact same generated `spec/` Git tree and differed only in generated metadata timestamps. They targeted an older `0.1.0` profile and did not constitute two distinct examples.

**Classification:** `DUPLICATE_GENERATED_ROBOT_PROFILE`.

### Removed checked-in exports

The old `export/` directory contained generated ROS 2 and Isaac artifacts without fixture assertions or independent authority.

**Classification:** `GENERATED_EXPORT_OUTPUT`.

### Removed historical external examples

The active `example/` directory previously carried three large URDF files:

- Berkeley Humanoid Lite — referenced absent local STL assets;
- iCub — referenced absent `package://iCub/meshes/...` resources;
- UR5 — contained a local controller IP and installation-specific paths and was generated from an external package.

None was a minimal, hermetic, redistribution-audited fixture exercised by CI.

**Classification:** `UNVERIFIED_EXTERNAL_EXAMPLE`.

A future example must be project-owned or have explicit redistribution provenance, be minimal and hermetic, contain no local deployment details, and be exercised by an automated test.

### Removed incomplete packaging and duplicate tooling

Also removed from active authority:

- incomplete `msix/` placeholder referencing absent executable/assets;
- competing Node bundle builder;
- duplicate Python unifier;
- benchmark-copy integrity command;
- unreachable parallel `src/cli.py`;
- stale `requirements.txt` and its generator.

All original paths and Git tree/blob identities are recorded in:

```text

```

The removed bytes remain recoverable from Git history without being duplicated in the active repository.

## Runtime ownership decision

### Canonical root

`OpenRGD/openrgd` owns:

- normative specifications;
- cross-component contracts;
- canonical hashing and deterministic compilation;
- validation tooling;
- importers;
- static Synapse exporters;
- seed/profile materialization;
- non-actuating compatibility/status commands.

It does **not** provide a physical embodied runtime or Body Adapter implementation.

### Independent runtime

A later reconciled runtime repository is expected to own executable orchestration for:

```text

      ↓
ActionIntent
      ↓
Somatic Translator
      ↓
CapabilityPlan
      ↓
Operation Safety Gate
      ↓
DecisionTrace
      ↓
Body Adapter
      ↓
Hardware
```

The final repository name remains open. Neither the empty `rgd-runtime` placeholder nor a recovered local snapshot is promoted automatically.

## Merge gates

Before merge, reviewers should explicitly decide:

1. whether `OpenRGD/openrgd` is accepted as the non-actuating canonical root;
2. whether candidate contracts remain appropriately located and labelled;
3. whether independent version axes are accepted;
4. whether `OPENRGD_SOURCE_TREE_SHA256_V1` is accepted as the standard/profile integrity profile;
5. whether generated products remain untracked under the adopted authority model;
6. whether the unavailable AION-ready artifact is recovered or explicitly excluded;
7. how `main` protection and required checks are configured.

Seed drift, bundled-runtime safety, generated-artifact ambiguity and canonical hash scope are closed on this branch.

## Release gates

A public release additionally requires:

- URDF importer reconciliation and owned fixtures;
- `check → boot → static export` lifecycle tests;
- static Synapse output assertions;
- artifact and commit signing policy;
- release notes distinguishing standard, toolchain and contract maturity;
