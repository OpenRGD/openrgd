## Runtime ownership decision

### Canonical root

`OpenRGD/openrgd` owns:

- normative specifications;
- cross-component contracts;
- validation and compilation tooling;
- importers;
- static Synapse exporters;
- seed/profile materialization;
- non-actuating compatibility/status commands.

It does **not** provide a physical embodied runtime or Body Adapter implementation.

### O-002 — Bundled runtime referenced a missing safety module

**Previous severity:** HIGH  
**Status:** RESOLVED BY QUARANTINE AND OWNERSHIP SEPARATION  
**Classification:** IMPLEMENTED PROTOTYPE → SUPERSEDED / HISTORICAL EVIDENCE

Recovered defects included:

- `RGDEngine` loaded nonexistent `02_operation/safety_supervisor.jsonc`;
- command validation collapsed safety to one generic scalar comparison;
- ROS 2 called undefined `engine.ingest_sense()`;
- ROS 2 actuation was `pass`;
- Viam THINK, ACT and `publish_intent()` were placeholders;
- direct adapter intent dispatch bypassed the convergence-candidate somatic, safety and audit layers;
- an alternate in-memory template generator independently recreated the same missing safety filename.

Resolution:

1. preserve the original source files and Git blob identities under `docs/history/runtime-prototype/`;
2. remove `src/openrgd/runtime/` and the stale `core/templates.py` generator from the installed package;
3. do not rename or reinterpret `safety_critical.jsonc` or `runtime_validation.jsonc` as the missing file;
4. retain `rgd run` only as a non-actuating migration/status namespace;
5. require legacy adapter commands to fail closed with exit code `2`;
6. enforce the boundary through `tools/validate_runtime_boundary.py` and CI.
