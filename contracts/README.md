# OpenRGD Cross-Component Contracts

This directory is the canonical repository location for interfaces shared across OpenRGD components.

Contract maturity is explicit:

- **candidate** — recovered or converged material under reconciliation; not yet a stable standard;
- **accepted** — approved through the OpenRGD governance process;
- **deprecated** — retained for compatibility and historical provenance, but no longer normative.

The current `agent/v0.1.0` package is a **convergence candidate**. Its presence in this repository does not imply that its decisions existed in the 2025 lineage, nor does it silently promote unresolved items to normative status.
