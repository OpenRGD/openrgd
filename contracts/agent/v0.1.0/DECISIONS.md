# Convergence decisions

## Frozen in v0.1

- `alignment.jsonc` / OpenRGD constitutional policy is the hard semantic authority; no new `bhl_dna.json` is invented.
- HyperAion512 is a cognitive representation, not final permission to actuate.
- `sigmoid(A·B)` may be used for soft resonance/ranking only after/under hard constitutional constraints.
- `ActionIntent` is the explicit model-agnostic action language.
- Somatic translation stops at declared capabilities; hardware-specific motor translation belongs to the body adapter.
- Chronons are canonical life/history evidence. Episodes, facts, skills, summaries and embeddings are projections.
- Ethos Packet stays a separate, temporally/causally bound forensic object; v0.1 does not assert `Ethos IS-A Chronon`.
- DecisionTrace contains structured evidence and policy outcomes, never private chain-of-thought.
- The historic Proof-of-Thought `causal_link` is evolved into causal Chronon references + structured cognitive commitments rather than raw reasoning hashes.

## Explicitly open

- semantic allocation of HyperAion dimensions 32..511;
- final canonical binary encoding for HyperAion vector commitments;
- Rate My Ethics runtime integration with the embodied agent;
- Ethos v4 post-hardening and GDPR erasure/tombstone policy;
- Robot Chronograf Ed25519 signing/key lifecycle;
- general multi-step/parallel Somatic ActionGraph planner;
- cross-agent/global Chronograf anchor resolution.

## Temporal facet extension

The embodied convergence profile adds `SOMATIC` as an extension facet for
hardware-agnostic capability plans. It does not represent raw motor telemetry;
that remains `PHYSICAL`.
