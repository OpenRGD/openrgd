# OpenRGD Examples

Start here.

```bash
rgd alive example/minimal-arm/openrgd_minimal_arm.urdf
```

or:

```bash
rgd alive example/minimal-arm/openrgd_minimal_arm.usda
```

These examples are deliberately small, self-contained and MIT-licensed. They contain enough mass, joints and limits to exercise the full `rgd alive` pipeline without downloading meshes or external packages.

The files are also used as test fixtures so the examples shown to new users stay executable.
